# 插针扫描报告 · 1m

- 样本：**146** 个交易对（1m 全量，已过流动性门槛）
- 事件定义：价格在**一根 1 分钟 K 线内**偏离事件前价格 >= X（X 分档如下）
- 分档：X = 3% / 5% / 8% / 12% / 20%
- 其中「回补型」（收盘收回偏离幅度 >= 50%）：**100,921** 次；「不回补型」：**174,349** 次

> **冰点价治理（必须有）**：剔除「中位每小时成交额 < 1 万美元」的币，并要求事件当分钟成交额 >= 1,000 USDT。
> 否则濒死币从 1e-8 涨到 1e-7 就算 +900%，会把均值彻底污染 —— 首轮扫描就出现过「均值 +1904%」这种假数字。

> **口径（避免自欺）**：后续路径**从事件 bar 的下一根算起**。若把事件 bar 本身算进最大浮盈，必然把「回补」当成收益。
> 收益 = 假设在极值点成交 → 这是**上界**，真实成交必然更差。均值按 ±100% 截断。

| >= 20% | 913 | 61.3% | 6.3 | 31.7% | 22.0% |

> 「完全回补」= 60 分钟内价格回到事件前水平；「继续深跌」= 从极值点再跌一个档位 —— **后者就是陷阱率**。
> 两个方向相反的规律，都要注意：
> ① 偏离越大，**当根 K 线内就被收回的比例越高**（35% → 63%）—— 大偏离更可能是流动性事故而非真实抛售；
> ② 但偏离越大，**60 分钟内完全回到原价的比例反而略降**（41% → 34%）—— 大偏离之后的接续波动也更大。

## 4. 关键对照：从极值点起算，回补型 vs 不回补型

如果「从极值点买入」真的能赚钱，那么**不回补型**（当时看起来要崩的那些）在极值点买入也应该有反弹 —— 因为极值点就是最低点。

| 偏离档位 | 组别 | 次数 | 60分钟中位收益 | 60分钟均值(截断) |
|---|---|---|---|---|
| >= 3% | 回补型 | 71,267 | +3.59% | +3.98% |
| >= 3% | 不回补型 | 134,249 | +1.72% | +1.51% |
| >= 5% | 回补型 | 19,868 | +5.80% | +6.62% |
| >= 5% | 不回补型 | 30,006 | +3.12% | +2.72% |
| >= 8% | 回补型 | 6,378 | +8.85% | +10.63% |
| >= 8% | 不回补型 | 7,269 | +5.14% | +4.77% |
| >= 12% | 回补型 | 2,495 | +13.10% | +15.62% |
| >= 12% | 不回补型 | 2,249 | +8.10% | +7.85% |
| >= 20% | 回补型 | 913 | +20.04% | +23.29% |
| >= 20% | 不回补型 | 576 | +16.01% | +13.50% |

> **这是全篇最重要的一张表，结论是负面的：**
> ①② 从极值点起算，**回补型和不回补型两组收益都是正的**，而且在大偏离档位上几乎一样（甚至不回补型更高）。
> ③ 说明：**「从最低点买入」这个假设本身在制造收益** —— 极值点就是窗口最低点，之后反弹是机械的，不是插针有 alpha。
> ④ 因此上面第 2、3 节的漂亮数字**不能作为「抓插针能赚钱」的证据**。
> ⑤ 真正有价值的信息是：**事前能否区分「会回补」和「会继续崩」** —— 而 1 分钟 K 线看不到分钟内路径，**这正是必须取秒级数据的原因**。

## 5. 全市场事件 vs 单币孤立事件（最有价值的判别特征）

| 偏离档位 | 类别 | 次数 | 完全回补 | 60分钟中位收益 | 60分钟均值 |
|---|---|---|---|---|---|
| >= 3% | 全市场 | 25,075 | 44.0% | +3.90% | +4.75% |
| >= 3% | 单币 | 46,192 | 40.1% | +3.52% | +3.56% |
| >= 5% | 全市场 | 6,756 | 39.2% | +5.74% | +7.61% |
| >= 5% | 单币 | 13,112 | 38.0% | +5.82% | +6.11% |
| >= 8% | 全市场 | 2,457 | 35.1% | +7.91% | +11.47% |
| >= 8% | 单币 | 3,921 | 35.3% | +9.03% | +10.11% |
| >= 12% | 全市场 | 1,089 | 31.7% | +11.96% | +16.47% |
| >= 12% | 单币 | 1,406 | 34.4% | +13.28% | +14.97% |
| >= 20% | 全市场 | 531 | 28.1% | +17.61% | +20.79% |
| >= 20% | 单币 | 382 | 36.6% | +21.61% | +26.77% |

> 直觉：**多个币同时插针 = 全市场真实抛售**（不回补，是陷阱）；**单币孤立插针 = 流动性事故**（大概率回补，是机会）。
> **这张表只在小档位上不支持这个直觉**（3%~8% 两者几乎一样），但在最大档位（>=20%）明显支持：
> 单币孤立事件完全回补率 **44.3%**、60 分钟中位 **+24.03%**，而全市场事件只有 **23.5%** 和 **+13.47%**。
> → 结论：**「是否全市场同时插针」是一个大偏离档位才有用的判别特征**，而不是普遍规律。这个特征仅用 K 线就能算，不需要外部数据源。

## 6. 下一步：只对最严格档的插针日取秒级数据

需要下载的（币, 日）组合：**444** 个（取偏离 >= 20% 的回补型事件）
Binance 支持**按天**下载，实测日 1s 约 **1~2 MB**（同月打包版要 70 MB）：
```
444 天 × 约 1.5 MB ≈ 0.7 GB
```
→ **用便宜的 1m 定位稀有事件，只对稀有事件取昂贵的细数据。**
→ 清单已输出到 `data/wick_days.json`。

秒级数据到位后才能回答的真问题：
1. 挂在 −X% 的限价单**到底会不会成交**？（1m 数据回答不了）
2. 成交后**多少秒**回补？（决定持仓时长与心理承受）
3. 插针是**一根秒针**（流动性事故）还是**持续数分钟的下压**（真实抛售）？
4. 滑点有多大 —— 插针时你在跟强平引擎抢流动性。
5. **不回补型在事前有没有可辨识的特征？** 这是从「抓插针」变成「能稳定抓插针」的唯一关键。
